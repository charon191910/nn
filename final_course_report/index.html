期末课程报告

1 项目概述

本学期围绕神经网络与强化学习课程，完成了两大方向的工作：

  1. CARLA自动驾驶研究平台构建 —— 基于CARLA仿真环境，实现了从强化学习轨迹规划、Lyapunov稳定性理论验证到完整实验分析系统的端到端研究平台
  2. 代码质量优化与重构 —— 对课程中多个核心模块进行代码重构，提升可读性、可维护性和工程规范性

累计提交 12个Pull Request，全部被上游仓库 OpenHUTB/nn 合并。

2 CARLA自动驾驶研究平台

2.1 项目背景

传统规则驱动的自动驾驶控制方法在复杂环境下适应性不足。本项目以CARLA仿真环境为载体，构建基于强化学习的轨迹规划与决策系统，支持多算法对比研究和理论验证。

2.2 核心模块开发

2.2.1 初始模块搭建（PR #5537）

新增CARLA自动驾驶汽车模块，建立项目基础框架：

  • 支持DDPG、PPO2、TRPO、A2C等多种强化学习算法
  • 实现Lyapunov理论驱动的安全塑形机制
  • 新增基线配置、改进换道塑形配置和Lyapunov理论配置三套实验方案

2.2.2 RL-Frenet轨迹规划算法套件（PR #5712）

在初始模块基础上，构建完整的算法研究平台：

  • Lyapunov稳定性算法：提供理论保证的强化学习
  • Frenet坐标系轨迹规划：复杂场景下的最优轨迹生成
  • 换道塑形奖励系统：密集学习信号，加速收敛
  • 课程学习支持：动态调整奖励权重和惩罚机制

2.2.3 理论验证与实验分析系统（PR #5741）

完善科研平台的理论和实验能力：

  • 理论验证框架：Lyapunov势能塑形理论、车辆动力学模型、安全屏障理论
  • 实验分析系统：基准算法对比、理论验证实现、结果可视化工具
  • 实验管理系统：批量实验运行、自动统计报告、性能对比图表

2.2.4 算法套件升级（PR #6196）

对轨迹规划算法套件进行深度优化：

  • 从233个文件精简到84个核心Python文件，专注核心功能
  • main.py作为单一入口，简化使用和部署
  • 支持A2C、DDPG、PPO2、TRPO、Lyapunov等算法性能对比

3 代码质量优化

3.1 RBM受限玻尔兹曼机优化（PR #5592）

对RBM实现进行深度性能优化和功能增强：

性能优化： - 添加scipy.special.expit加速sigmoid函数（SIMD C实现，快2-3倍） - 修复v1版本的masked-exp BUG - 矩阵乘法out=参数和预分配缓冲区，消除batch级内存分配 - 动量更新全in-place操作

功能增强： - PCD（Persistent Contrastive Divergence）选项 - CD-k可配置（默认k=1） - 批量Gibbs采样（多链并行） - 自由能监控

3.2 CNN TensorFlow代码优化（PR #5227）

将CNN_tensorflow.py从TF1迁移至TF2 Keras API，识别准确率从约99%提升至99.53%：

  • API迁移：tf.placeholder/tf.Session迁移为tf.keras.Model/tf.keras.layers
  • 模型架构升级：预激活残差块替代单层卷积堆叠，参数从340万降至44万
  • 正则化增强：L2权重衰减 + SpatialDropout2D + 标签平滑
  • 数据增强：随机旋转、平移、缩放（避免6/9混淆）
  • 学习率策略：Warmup + 余弦退火调度

3.3 DQN网络结构优化（PR #6436）

对AirSim控制模块中的Q网络进行架构优化：

  • 从2个隐藏层扩展到3个隐藏层，增强表达能力
  • 添加LayerNorm减少内部协变量偏移
  • LeakyReLU替代ReLU，防止神经元死亡
  • Xavier权重初始化，中间隐藏层维度从128扩展到256

3.4 车道线检测代码重构（PR #6669）

将单体脚本拆分为独立函数模块：

  • 新增车道线按斜率分类（左/右车道）及多项式拟合平均
  • 半透明车道区域填充叠加显示
  • 四宫格组合对比图输出

5 总结与收获

5.1 技术收获

  • 强化学习实战：掌握了DDPG、PPO2、TRPO等主流RL算法的实现与调参
  • 理论与实践结合：将Lyapunov稳定性理论应用于自动驾驶安全保障
  • 工程能力提升：通过大量代码重构，养成了模块化、规范化编码习惯
  • 仿真环境使用：熟悉了CARLA和AirSim等自动驾驶仿真平台

5.2 改进方向

  • 目前算法主要在仿真环境验证，后续可探索Sim2Real迁移
  • 可引入更多感知模块（如激光雷达、V2X通信）提升系统完整性
  • 实验管理可进一步自动化，支持超参数搜索和A/B测试
